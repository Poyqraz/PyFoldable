# First-party synthetic propeller reference

This legacy directory name is retained temporarily so existing example paths remain
stable. It contains no APC geometry or performance table. The former normalized APC
derivative was removed after review of the source terms.

`PYFOLDABLE_REFERENCE_10x4.7.csv` is a deliberately small, first-party synthetic
fixture for software-flow tests and examples. It is not a manufacturer model,
measurement, aerodynamic validation source, or qualification evidence. Physical
PR-06C screening uses the separately attributed UIUC fixture and accepts APC PE0
geometry only as an explicit user-local input.
