# APC 202602 normalized performance table

`APC_10x4.7SF.csv` is a normalized project copy derived from APC Propellers release
`PERFILES_WEB-202602`. APC describes these performance files as predictions from its
proprietary vortex-based analysis using actual propeller geometry. They are useful as
a manufacturer-model reference, but they are not experimental validation.

- Source: <https://www.apcprop.com/technical-information/performance-data/>
- Identity and evidence class: `APC_10x4.7SF.json`
- License boundary: third-party source terms apply; the root PyFoldable license does
  not relicense this table.

PR-06C physical screening therefore uses the attributed UIUC wind-tunnel fixture under
`tests/fixtures/rotor_benchmark/` rather than treating this table as measurements.
